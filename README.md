# Coffee Sales Analysis — SQL & Power BI

## 📌 Project Overview

This project analyses coffee shop sales data to identify sales performance, revenue trends, customer purchasing patterns, and payment behaviour.

The project combines *SQL data analysis* with *Power BI data visualisation* to transform raw sales data into meaningful business insights.

---

## 🛠️ Tools & Technologies

* SQL / MySQL — Data querying and analysis
* Power BI — Interactive dashboard and data visualisation
* Excel / CSV — Data source and preparation
* GitHub — Project documentation and version control

---

## 🔍 SQL Analysis

SQL was used to explore and analyse the coffee sales data.

The analysis included:

* Total revenue
* Total transactions
* Average transaction value
* Sales by coffee type
* Revenue by coffee type
* Sales trends over time
* Cash vs card transactions
* Revenue by payment type
* Identification of top-performing coffee products

The SQL analysis helped identify patterns and trends that were later presented visually in Power BI.

---

## 📊 Power BI Dashboard

The SQL analysis was transformed into an interactive *Coffee Sales Analysis Dashboard* in Power BI.

### Key Performance Indicators

The dashboard provides:

* Total Revenue by Coffee Type**
* **Total Revenue by Year**
* **Total Revenue by Payment Type**
* **Total Transactions by Payment Type**

### Interactive Filters

Users can filter the dashboard by:

* Year
* Coffee Type
* Payment Type

---

## 💡 Key Insights

The analysis showed that:

* Card payments account for the majority of transactions and revenue.
* Coffee sales generate approximately **$122K in total revenue** across the dataset.
* There are **33 distinct coffee types** represented in the data.
* The dashboard allows revenue performance to be compared across coffee types and years.
* Payment behaviour can be compared between cash and card transactions.
